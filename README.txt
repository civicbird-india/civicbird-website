2. Upload the contents (the HTML files and assets folder) to the public web root of your hosting account (often public_html).

4. Set index.html as the default homepage.
5. Open index.html and test on mobile and desktop.

IMPORTANT BEFORE PUBLIC LAUNCH:
- This is a front-end starter, not a live production booking platform.
- Razorpay is NOT integrated. Do not collect the ₹149 fee or service payments until a verified backend/payment flow and receipts are implemented.
- Firebase authentication, mobile OTP, forgot-password email, live booking submission, staff assignment, and customer booking history are NOT connected.
- Forms do not transmit data to a server. Login/signup/help/application forms only demonstrate UI validation.
- Location is requested only after the customer presses the location button. The page can use browser geolocation on HTTPS.
- The Bird application form intentionally does not upload or store identity files. Aadhaar front/back are highly sensitive. Implement secure backend storage, access controls, legal review, retention/deletion, and a lawful alternative before collecting them.
- The owner image was not supplied; the uploaded image was a pricing screenshot. On the About page, choose a portrait locally to preview it. This preview is not saved to the website. To publish a portrait, provide the actual photo and it can be added as an asset.
- Safety wording avoids claiming a specific individual is verified before verification actually happens.
- Review GST applicability, pricing, ₹149 fee/refund policy, privacy policy, terms, and police verification process with qualified advisers before launch.
